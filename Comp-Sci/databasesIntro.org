* Database Concepts
An entity is a catogory of object which data is to be recorded in. Enities can hold attributes
which is the actual data being held.


** Flat File Databases
Flat Files databases consist of a single file; hold a single entity in a structured manner and have no
relationships, constraints or indexing.

** Entity Identifiers
In a relational database, unique identifiers are known as a primary keys.
Typical attributes wont serve as a primary keys' as they are not necessarily unique
so it is up the database engine to create and manage unqiue Primary Keys for indexing.

*** Secondary Keys
Entities can be indexed in other ways then just primary keys, an attribute such
as surname or username can be used to identify entities. So a secondary key is any
attribute that can be used to identify an entity.
